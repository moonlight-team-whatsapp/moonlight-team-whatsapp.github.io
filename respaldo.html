Respaldo

Descarga una copia de todos los datos de la web (solo admin).

Pulsa el botón y se descarga un único archivo moonlight-respaldo.json con todas las colecciones. Pásamelo para migrar los datos a Supabase. Guárdalo en un sitio privado: incluye datos de miembros.

Migración a Supabase: copia todos los datos de Firestore a las tablas de Supabase (las deja idénticas). Se puede repetir todas las veces que quieras; no toca Firestore.
